# Personal Portfolio

A static portfolio built with HTML, CSS, and JavaScript. It includes an introduction, skills, project examples, and a contact section.

## Preview locally

From the repository root, start a static file server with Python 3.

```sh
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000). The page loads some visual libraries from CDNs. The contact form uses EmailJS.

## Files

- `index.html` contains the page and portfolio content.
- `css/` contains the styles.
- `js/` contains interactions and configuration.
- `img/` contains profile and project images.
